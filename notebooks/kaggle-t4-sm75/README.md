# Kaggle T4 (SM75) notebooks

`notebooks/` holds the 14 unexecuted source notebooks (01–14). Run them on Kaggle with *Accelerator: GPU T4 × 2*, Internet ON, Python 3.13.
01–06 are maintained by hand; 07–14 are generated by `python scripts/make_notebooks.py`.

| # | Notebook | What it proves |
|---|---|---|
| 01 | environment audit | Kaggle runtime matches the target |
| 02 | installation | wheels install, protected packages untouched |
| 03 | single GPU | CUDA/Triton/native ops on both T4s |
| 04 | dual-GPU NCCL | collectives on both ranks |
| 05 | vLLM inference | TP=1 and TP=2, `TRITON_ATTN` |
| 06 | TP benchmark | TP=1 vs TP=2 |
| 07 | GPU topology | UUIDs, link class, peer access |
| 08 | pipeline parallel | PP=2 |
| 09 | replicas | `ReplicaPool` |
| 10 | CUDA communication | host-staged transport vs NCCL |
| 11 | load balancing | strategy comparison, imbalance % |
| 12 | consolidated | roll-up |
| 13 | TP / PP fulfilment | strict TP=1, TP=2, PP=2 checks |
| 14 | replica balance | both replicas receive work after warm-up |

Executed copies with outputs (and the per-notebook acceptance ZIPs) are kept locally in `notebooks-executed-with-output/` at the project root and are not published; the summary is in [docs/KAGGLE_T4_VERIFICATION.md](../../docs/KAGGLE_T4_VERIFICATION.md).
