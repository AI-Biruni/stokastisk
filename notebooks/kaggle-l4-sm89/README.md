# Kaggle L4 (SM89) — `PLANNED_NOT_IMPLEMENTED`

Nothing here is implemented. There are no SM89 binaries, no L4 wheel, no L4 notebooks and no L4 performance data, and Stokastisk 0.1.0 makes **no claim** of L4 support.
The T4 (SM75) build must not be reused for L4: its native objects contain `sm_75` cubins only.

Planned, in order, only once the owner asks for it:
1. an SM89 native build (CUDA 13.0, `sm_89` cubins) with its own manifest and hashes;
2. an L4-specific release name, separate from `stokastisk-0.1.0-kaggle-t4-sm75`;
3. L4 notebooks, run by the owner on a real L4;
4. only then, support statements backed by that evidence.

The project version stays `0.1.0` (see `VERSION_POLICY.md`).
