# Build / reproduce
Toolchain: CPython 3.13, `build`, `setuptools`, `packaging`. No Docker, virtualenv or uv. A GPU is **not** needed (and the local GeForce 940M must not be used): the native objects come from the byte‑pinned vLLM wheel.

1. Put the pinned base wheel at `inputs/vllm-0.25.1-cp38-abi3-linux_x86_64.whl` (SHA256 `cc3bcafb6516791990ca302073ae153a08465d3df1e460d666e3ec09b4e98f5e`; GitHub release asset of `v0.1.0`). It was produced from vLLM 0.25.1 with `scripts/build_vllm_sm75.sh` (CUDA 13.0 only, `sm_75`).
2. **Any build (current: 4):** `python3.13 scripts/release/build_wheel_release.py --build-tag 4 --out dist/wheel-build4 [--reference-wheel <previous wheel> --allow-sdk … --docstring-only … --ast-identical …] --reproduce`. It builds the Flash‑free wheel (`build_integrated_wheel.py` → `t4_flash_free.py`), verifies it independently (`scripts/audit/verify_integrated_wheel.py`), optionally compares it member by member with a previous wheel when you pass one (`scripts/audit/wheel_delta.py`: vLLM files, native binaries and dependency pins must be identical, SDK changes limited to the allow‑list; there is no reference wheel for build 4 any more), rebuilds it to prove reproducibility, and writes `release-manifest.json` with separate fields for what was executed on Kaggle (inherited, with source) and what was not (this build). It never overwrites anything and never touches a GPU. `dist/` is local and git‑ignored.
3. Dependencies: `python3.13 scripts/release/lock_closure.py requirements/kaggle-baseline-2026-11-13.json requirements/<profile>.roots requirements/<profile> --cache <dir>` regenerates a lock from its `.roots`.
4. Tests: `CUDA_VISIBLE_DEVICES= python3.13 -m pytest tests -q`.
5. Publish: the wheel goes to Hugging Face `wheels/`; `python3.13 scripts/release/make_pip_index.py <wheel> <dir>` writes the PEP 503 pages for the `gh-pages` branch (GitHub Pages). Users install with the SHA256‑pinned command in [INSTALL.md](INSTALL.md) (the new hash goes into `RELEASE.json`, `INSTALL.md`, `RELEASE.md`, `README.md`, `docs/HUB_README.md`, the guide and the notebooks; `tests/test_release_consistency.py` fails if any of them disagree). After publishing, download the Hugging Face file again and compare its SHA256 before announcing it.
